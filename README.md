# Beam Designer

Beam Designer is a Python desktop app for analyzing simply supported beams and cantilevers. It calculates reactions, shear, moment, and elastic deflection; shows preliminary bending and deflection checks; and can save/open designs and export results to CSV or a PDF calculation sheet. It is an educational screening tool, not a code-compliant design program.

## Install

Install the required packages from PowerShell in this folder:

```powershell
py -m pip install -r requirements.txt
```

The requirements are NumPy and Matplotlib.

## Start

```powershell
py beam_designer.py
```
